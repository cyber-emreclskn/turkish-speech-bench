🇹🇷 Turkish Speech Bench

How accurate and how fast are Turkish speech recognition models on ordinary CPUs? Every number was measured with the open-source turkish-speech-bench tool, using Turkish-aware normalization (I/ı, İ/i, apostrophes, circumflex), with the hardware recorded next to each result.

WER / CER — word / character error rate, lower is better.
RTFx — seconds of audio transcribed per second; higher is faster, > 1 is faster than real time.
p90 latency — 90% of utterances finished within this time.
Peak RAM — whole-process memory during the run.

Add your hardware (kiosks, NUCs, laptops are especially welcome):

pip install "turkish-speech-bench[whisper,vosk]"
tsb run -m faster-whisper:small -m vosk:vosk-model-small-tr-0.3 -n 200 --label "my-cpu"
